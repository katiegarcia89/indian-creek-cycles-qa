# Indian Creek Cycles QA Project

## Project Overview

This repository documents the quality assurance testing performed on the
Indian Creek Cycle Rentals web application.

Indian Creek Cycle Rentals was originally developed as a team capstone project
for a Computer Information Systems course. This QA project revisits the
completed application from a tester's perspective to identify defects,
evaluate usability, verify core functionality, and document testing results.

## Application Under Test

**Application:** Indian Creek Cycle Rentals  
**Website:** https://www.indiancreekcycles.com

The application allows customers to browse bicycle rental options and interact
with features related to the rental process.

## Project Goals

The goals of this project are to:

- Create and execute structured manual test cases
- Perform exploratory testing
- Identify functional and usability defects
- Document defects with clear reproduction steps
- Evaluate form validation and error handling
- Test the application across different browsers and screen sizes
- Perform regression testing after defects are corrected
- Demonstrate practical QA documentation and testing skills

## Testing Scope

Testing may include:

- Navigation and links
- Page content and layout
- Forms and input validation
- Rental-related workflows
- Error messages
- Responsive design
- Browser compatibility
- Accessibility observations
- Database-related behavior
- General usability

## Testing Types

- Functional testing
- Exploratory testing
- Usability testing
- Negative testing
- Boundary testing
- Compatibility testing
- Responsive testing
- Regression testing

## Test Environment

Testing will be performed using a combination of:

- Google Chrome
- Microsoft Edge
- Safari
- Desktop and mobile screen sizes
- macOS
- Windows

Additional environments will be documented as testing progresses.
