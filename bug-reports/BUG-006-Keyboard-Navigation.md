# BUG-006: Continuous Keyboard Navigation Requires Mouse Interaction

## Summary
Keyboard navigation cannot be performed continuously throughout the website without using the mouse.

## Environment
- Application: Indian Creek Cycles
- Browser: (Enter browser used)
- OS: (Optional)

## Severity
Medium

## Priority
Medium

## Steps to Reproduce
1. Open the Indian Creek Cycles website.
2. Navigate using only the keyboard (Tab, Shift+Tab, Enter).
3. Move between the navigation menu and page content.
4. Continue navigating throughout the website.

## Expected Result
Users should be able to navigate all interactive elements using only the keyboard without requiring mouse interaction.

## Actual Result
Keyboard navigation worked within individual page sections. However, moving between the header navigation and page content required clicking somewhere on the page before keyboard navigation would continue.

## Impact
Users relying on keyboard-only navigation cannot move through the website continuously without using a mouse.
